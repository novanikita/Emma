# Регламент: как приносить сырьё

Номер и название — жирный подзаголовок. Каждый критерий с новой строки. Название критерия (Номер, Тег, Автор, Дата и дальше) тоже жирным.

Пустых отступов и списков нет. Поля идут по колонкам таблицы.

**Номер** — колонка таблицы: порядковый номер добавления информации, не рейтинг и не важность. В одной пачке нумерация сквозная, начиная с 1.

Тегов можно несколько, через запятую. Автор — автор продукта или исследования. «Почему привлекло внимание» входит в блок «Что произошло».

## Шаблон

**№N Название**

**Номер:** N

**Тег:** продукт, событие, запуск, провал, успех, исследование, мнение

**Автор:** компания / человек / команда

**Дата:** ГГГГ-ММ-ДД

**Ссылка:** URL

**Что произошло:** описание явления и почему оно привлекло внимание

**Тип источника:** журналистика / наука / вендор / аналитик / пользователь / другое

**Key note:** ключевые пункты; по делу — размер актора, монетизация, язык рынка, демо/прод/статья

## Пример

**№1 Название голосового помощника**

**Номер:** 1

**Тег:** событие, провал

**Автор:** название компании

**Дата:** 2024-06-11

**Ссылка:** https://example.com

**Что произошло:** текст

**Тип источника:** журналистика

**Key note:** текст
